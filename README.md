# Juego 1: Paint

Este repositorio contiene `paint.py`, un programa de dibujo en Python basado en Paint de Free Python Games. Permite seleccionar colores y dibujar figuras mediante dos clics.

## Cambios realizados

- Se agregó el color amarillo, que se selecciona con la tecla `Y`.
- Se completó la función para dibujar círculos, calculando el radio con la distancia entre los dos clics.
- Se implementaron las figuras de rectángulo y triángulo.

Mi aportación fue agregar el color amarillo y completar la función del círculo.
