# Juego 1: Paint

Este repositorio contiene `paint.py`, un programa de dibujo en Python basado en Paint de Free Python Games. Permite seleccionar colores y dibujar figuras mediante dos clics.

## Cambios realizados por mí

- Agregué el color amarillo, que se selecciona con la tecla `Y`.
- Completé la función para dibujar círculos, calculando el radio mediante la distancia entre los dos clics.

## Cambios realizados por mi compañero

- Completó la función para dibujar rectángulos usando dos esquinas opuestas.
- Completó la función para dibujar triángulos.

Estos cambios permiten utilizar más colores y figuras dentro del programa.
